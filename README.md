## 🌍 Parametric Trigger System

ArthaShield uses a **dual-gate trigger system**:

> **Primary: Event threshold breached**  
> **Secondary: Income/activity confirmation**

---

### 📡 Trigger Signals

#### 🌧️ Extreme Rainfall
- > 50 mm/hr OR > 100 mm/day  
- + zero deliveries in zone  

#### 🌫️ Hazardous AQI (Unique)
- AQI > 300 for 2+ hours  
- + worker active  

#### 🚫 Civic Disruption
- Curfew / strike in zone  
- + recent activity  

#### 🏪 Dark Store Hub Closure (Q-Commerce Specific)
- Hub OFFLINE  
- + worker active  

#### 🚧 Route Blockage
- All routes blocked / flooding  
- + rainfall confirmed  

---

### 🧾 Decision Logic

| Condition | Outcome |
|----------|--------|
| Event + income loss | ✅ Payout |
| Event only | ❌ No payout |

> 📍 Operates at **3 km zone level**, not city level

## 🤖 AI & Fraud Defense

> We don’t verify location.  
> **We verify behavior.**

---

### 📱 Behavioral Signals

---

## 🛡️ Multi-Layer Fraud Defense

### Layer 1 — Behavioral Validation
Detects mismatch between claimed activity and real movement

### Layer 2 — Cluster Detection (DBSCAN)
Identifies coordinated fraud groups using:
- Location clusters  
- Timing bursts  
- Device similarity  
- Network patterns  

### Layer 3 — Fairness System

| Risk Level | Action |
|-----------|--------|
| Low | ✅ Instant payout |
| Medium | ⏳ Soft hold (auto-resolved) |
| High | 🔍 Manual review |

> 💡 Honest workers are never denied — only verified
